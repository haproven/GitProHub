GitProHub v1 — Build Flow

Step 1: Basic backend setup
→ backend folder
→ package.json
→ src/server.js
→ Run करके check करेंगे: Server running ✅

Step 2: GitHub API connection
→ githubService.js
→ .env में GitHub Token
→ GitHub username/repo data test

Step 3: gitprohub.md parser
→ Markdown file पढ़ना
→ title, description, category, etc. निकालना

Step 4: GitHub Discovery
→ GitHub पर gitprohub.md वाले repos ढूँढना

Step 5: Auto + Manual Data Combine
→ GitHub का automatic data
→ gitprohub.md का custom data
→ Final project object

Step 6: Database / Project Index
→ Projects save/update करना

Step 7: API
→ /api/projects
→ /api/projects/:id

Step 8: Simple Frontend
→ Project cards
→ Search
→ Category

Step 9: Webhook
→ Developer git push करे
→ GitProHub project जल्दी update हो

Step 10: Final testing + deploy 🚀

अब Step 1 से शुरू करते हैं।
मैं हर step में सिर्फ जरूरी files + पूरा copy-paste code दूँगा, फिर पहले उसे run करवाएँगे।
