Discovery API

GitHub repositories se gitprohub.md ko discover karke project information ko API ke through access karein. Developers apne projects ko ek simple file ke through GitProHub ecosystem me expose kar sakte hain.

How Discovery Works

GitProHub repository ko scan karta hai aur root level par available gitprohub.md file ko project metadata ke source ke roop me use karta hai.

01
GitHub Repository Public repository available hoti hai.

GET STARTED

Add Your Project

GitHub repository me sirf gitprohub.md add karein aur GitProHub aapke project ko automatically discover kar sakta hai.

01

Create the File

Apne GitHub repository ke main/root level par gitprohub.md file banayein.

📄 gitprohub.md
GitProHub Template 
# Project-Name

## Project

title: Project Name Yahan
description: Short clear description of the project (1-2 lines).
category: Category Name (jaise Developer Tools, Technology Community, Showcase Platform, Developer Profile, Local Information Platform etc.)
status: Active
image: https://full-image-url-here (optional, project banner/screenshot)

## Links

live: https://your-live-website-url/
demo: https://demo-url-if-any/
documentation: https://docs-url-if-any/

## Discover

tags: tag1, tag2, tag3, tag4, haproven, open-source
featured: true
open_source: true
02

Put It in Root

gitprohub.md ko repository ke main/root level par rakhein. GitProHub isi location par file ko identify karta hai.

📦 your-repository/
  ├── 📄 gitprohub.md
  ├── 📄 README.md
  └── 📁 src/
✓ Required /gitprohub.md
Why Root? Discovery scan root level par file ko identify karta hai.
Important /src/ ya /docs/ ke andar file na rakhein.
03

Commit & Push

File repository me add karne ke baad GitHub par commit aur push karein.

1
git add gitprohub.md
2
git commit -m "Add GitProHub card"
3
git push
✓ Repository GitHub par publicly accessible honi chahiye.

Requirements

GitProHub discovery ke liye repository ko ye basic requirements follow karni chahiye.

✓
Public repository
Repository GitHub par publicly accessible honi chahiye.
✓
Root-level file
gitprohub.md repository ke root me honi chahiye.
✓
Exact filename
Filename exactly gitprohub.md hona chahiye.
✓
Project metadata
File me project ki required information available honi chahiye.

API Endpoints

GitProHub project discovery aur project data access karne ke liye available endpoints.

GET Discover GitHub User Projects
/api/github/USERNAME

GitHub username ke repositories ko scan karke discoverable GitProHub projects return karta hai.

Example 
GET /api/github/codersusheel
Try Endpoint →
GET Get Specific Project
/api/project/USERNAME/REPOSITORY

Kisi specific GitHub repository ke GitProHub project data ko retrieve karta hai.

Example 
GET /api/project/codersusheel/haprocard
GET Get All Projects
/api/projects

GitProHub me currently available discovered projects ka collection return karta hai.

Try Endpoint →
