Apne GitHub repository me sirf haprocard.md add karke apne project ko GitProHub par discoverable banayein.

01
📁

File Create Karein

Apne GitHub repository ke root directory me ek file create karein.

File Name haprocard.md
Important: File ka naam exactly haprocard.md hona chahiye.
02
📍

File Kahan Rakhein?

File ko kisi folder ke andar nahi, repository ke main/root level par rakhein.

📦 your-repository/
└── 📄 haprocard.md
└── 📄 README.md
└── 📁 src/
Correct: /haprocard.md
03
✍️

04
🚀

GitHub Par Push Karein

File add karne ke baad changes ko commit karke GitHub repository par push karein.

git add haprocard.md git commit -m "Add GitProHub card" git push
GitHub repository public honi chahiye taaki GitProHub project ko discover kar sake.
05
🔍

Project Discover Hone Dein

GitProHub repository ko scan karta hai aur haprocard.md milne par project ko detect karta hai.

GitHub → Scan → Detect → Project

✅

All Projects https://gitprohub.onrender.com/api/projects
