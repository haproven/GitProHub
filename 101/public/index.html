Add Your Project

GitHub repository me sirf haprocard.md add karein aur GitProHub aapke project ko automatically discover kar sakta hai.

01
📄

Create the File

Repository ke root me ye file banayein.

haprocard.md 
# HaproID

## Description

HaproID is a verified digital identity and profile platform.

## Status

In Development

## Category

Developer Tool

## Author

Susheel Kumar

## Organization

## GitHub

https://github.com/haproven/haproid

## Image

https://haproid.netlify.app/assets/og-image.png
02
📍

Put It in Root

Apne GitHub repository ke main/root level par haprocard.md file add karein. GitProHub isi file ko project card ki information ke liye read karta hai.

📦 your-repository/
  ├── 📄 haprocard.md
  ├── 📄 README.md
  └── 📁 src/




Required: /haprocard.md
Why Root? GitProHub repository scan karte waqt root level par haprocard.md ko identify karke project details read karta hai.
What Happens? File detect hone ke baad usme di gayi project information GitProHub ke project card/API data me use ki ja sakti hai.
Important: File ka naam exactly haprocard.md rakhein. /src/, /docs/ ya kisi subfolder ke andar na rakhein.
03
🚀

Commit & Push

File add karne ke baad GitHub par push karein. 

git add haprocard.md
git commit -m "Add GitProHub card"
git push
Repository public honi chahiye.

🔍
